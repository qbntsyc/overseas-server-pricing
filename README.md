## 国外服务器租用到底在买什么

买的是三样东西：硬件归不归你、数据走哪条路回中国、带宽是怎么算的。这三项决定了同样标价的两台机器，实际体验能差出一倍。

**独立服务器和云服务器不是替代关系。** 独立服务器是整台物理机归你，CPU、内存、硬盘全部独享，性能可预期，适合长期跑高负载、数据库、需要装特殊驱动或独立 IP 段的业务。缺点是一旦配置定死，升级要停机换硬件。云服务器反过来：分钟级开通、随时升降配、按需付费，代价是共享底层资源。一个很实际的信号是，有商家的美国云主机页面直接写着“该机房暂无在售套餐”，同一家同一天的美国独立服务器页面却有 16 档在售。云主机整机房停售并不罕见，你买的是随时可能被调整的库存。

**回国线路决定你在国内打开它快不快。** 洛杉矶机房到国内的物理延迟摆在那，谁也不能违反物理。差别在走什么线路回国。有商家把线路写得很细：国际 T1 网络加中国电信 CN2、中国联通 CUG 精品网、中国移动 CMI，三网直连，双向 CN2 GIA，标称延时约 130–160ms。另一家只写“BGP 优质机房”“Tier3+”，不给具体数字。两种描述都可能是真的，但只有给了延时区间和线路名称的，你才有办法在下单前判断它适不适合你。看到“低延迟访问亚太”这种描述，就当没说。

**“不限流量”和“独享带宽”是两件事。** 这条最容易被忽略。有服务商在 FAQ 里写得很直白：产品带宽默认共享，只有标注了“保证带宽”的才是独享；国际带宽受国际出口拥塞影响，仅保证 99% 时间段达到标称带宽。所以“1G 不限流量”通常意味着“1G 端口共享，不限制你跑多少 GB”，不意味着你随时能跑满 1Gbps。真需要稳定带宽的业务，下单前必须问清楚是共享还是独享。

## 下单前必须问清的四件事

这四条都写在条款或 FAQ 里，销售页面不会主动提，但每一条都能让你多花钱或者退不了款。

**退款退到哪里。** 有服务商的规则是：正价商品流量不超过 10G 可全额退款，但退到网站账户余额，不是原路退回。同时三种情况一律不退：流量超过 10G、分配到的 IP 被 GFW 或所在地区封锁、参与促销或使用过优惠码。也就是说，用折扣价买的机器，基本等于放弃退款。雨云这边的公开口径是 7 天无理由退款到余额，每人 3 次机会，同样不是原路退。

**IP 归属地可能和机房所在地不一致。** 有的服务商明说所用 IP 都是广播 IP，你查归属地可能显示为其他地区，也不承诺 100% 能访问有特定要求的网站。做本地化业务、要投广告、要过平台审核的，这一条必须先确认。

**取消要提前多久说。** 英国机房那家的规则是提前 7 个工作日通知取消或不续费，低于 7 天才操作的，机房可能额外收 300 元手续费。月付机器看着灵活，忘取消一样扣钱。

**Windows 是不是另外算钱。** 有商家明确报价默认 Linux，装 Windows 要额外付费。另一家则写 Windows 2008／2012／2016／2019／2022 和 Ubuntu、CentOS、Debian、Rocky 都能装，宝塔、AMH、WDCP、phpstudy 也都支持，需要协助可以提工单。要跑 Windows 应用的，下单前把这一项问清楚，不然装系统时才发现要加钱。

## 常见问题

**国外服务器需要备案吗？**
境外节点通常免备案，买完直接部署。但免备案不等于什么都能放，各家的禁止业务清单不一样，而且宽严差别很大。有服务商在禁止条款里明确列了“跨境访问节点”，和色情、赌博、黑客工具并列，发现即停服且不退款。买之前把目标商家的禁售清单读一遍，比看配置表重要。

**多久能拿到机器？**
量级差得挺多。有商家写“正常情况下一个小时左右即可交付”，有商家写“常规配置确认订单后快速开通，涉及定制硬件交付时间随方案复杂度调整”，还有的写“付款后 3 个工作日内交付”。云主机的开通速度又是另一个量级，分钟级。急着上线就选标了明确小时的，别赌“快速”。

**能装宝塔和 Windows 吗？**
能不能装，取决于商家给不给你 root 和 ISO。上面提到的四家里，华纳云明确写了支持 Windows 全系和主流 Linux，面板支持宝塔等；天下数据默认 Linux，Windows 加钱；两家美国商家提供 IP 和 SSH 权限，面板自行安装。买之前问一句“能不能挂 ISO”，比问“支持什么系统”更能得到确切答复。

**年付到底能省多少？**
没有一个行业统一价。华纳云的年付价正好是月付乘 10，等于省两个月；天下数据写“年付仅需 10 个月”，省的比例一样但表述不同；idcl 只写“年付价格更优，以购物车结算为准”，页面不公布具体折扣。雨云的公开整理口径是季付 9 折、半年 8 折、年付 7 折，可以和新人券叠加。想算清楚真实成本，把年付总价除以 12 和月付价比，别只看折扣百分比。
